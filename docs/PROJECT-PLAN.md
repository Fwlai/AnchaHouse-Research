# Ancha House - Project Plan

## Project overview

Ancha House is a small multiplayer 2D fantasy world centered on a large magical castle. It is intended for a small group of friends, with a first presentable release targeted for Nowruz 1406 (around March 2027).

## Project boundaries

- Ancha House is independent from PixelTest.
- Do not modify PixelTest or copy its character sprites into Ancha House.
- PixelTest may be used as a technical reference for movement, camera following, and rendering behavior.
- Character sprites and environment assets should be selected from Stendhal or other sources whose terms have been documented.

## Visual direction

- 2D top-down fantasy world with four-direction character movement.
- A large central castle with towers, walls, walkways, an arched entrance, rooms, multiple floors, courtyard, garden, and hidden areas.
- Social interactions and small activities for friends.
- Main menu concept: a decorative rotating 3D castle on the left, menu buttons on the right, background music, and a pixel witch on a broom.

## Research priorities

1. Character sprite layout, directions, and animations.
2. Castle walls, towers, doors, roofs, and architectural pieces.
3. Ground tiles, paths, vegetation, and courtyard decorations.
4. Furniture, interior tiles, and room layouts.
5. Creatures and optional sprites.
6. Music and sound candidates.
7. Camera, drawing order, and animation implementation references.
8. Hosting and GitHub Actions deployment options.

## Important asset rule

Do not assume all files in one game or asset pack share the same license. Track the exact source, creator, license, attribution text, and redistribution obligations for every selected asset before including it in a release.

## Current status

Research and asset selection only. No Stendhal code or assets have been integrated into the game yet.
