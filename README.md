# Ancha House

An independent small multiplayer 2D fantasy castle world for friends.

## Play the first prototype

Open [`index.html`](index.html) in a modern browser. The first walkable sketch has a top-down castle courtyard, four-direction movement, collision, touch controls, and a basic interaction prompt. It uses placeholder art and has no build step.

## Project boundaries

- Ancha House is separate from PixelTest.
- PixelTest must remain untouched.
- PixelTest may be used only as a reference for movement, camera behavior, and rendering ideas.
- Third-party assets must not be treated as approved until their exact source, creator, license, attribution, and redistribution obligations are verified.
